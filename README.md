## 📌 About
This is my personal portfolio website where I showcase my projects and professional background.  
It’s built with **React, Vite, TailwindCSS, and React Router**, and deployed on **Render**.  

The goal of this portfolio is to present my work in a professional way, including case studies of each project, links to demos, and source code.

---

## 🚀 Features
- Home with intro and typing effect
- About section with skills and experience
- Projects grid with case studies and live demos
- Responsive design (desktop and mobile)

---

## 🛠️ Stack
- **React 18**
- **Vite**
- **TailwindCSS**
- **React Router**
- **Deployed on Render**
